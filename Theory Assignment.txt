Que - 4 Describe asynchronous programming in Dart, including Future, async,await and stream.
Ans- Asynchronous Programming:- In simple words it is a type a time consuming process. You have multiple tasks at a
same time.  It is mainly used to fetching data from internet, reading files, delays and timer
Dart provides several features for asynchronous programming:
1. Future

A Future represents a value that will be available later.
It is used when a task takes some time to complete.
Ex:-
Future<String> fetchData() {
  return Future.delayed(
    Duration(seconds: 2),
    () => "Data Loaded",
  );
}

2. async

The async keyword is used with a function to make it asynchronous.
It allows the function to use await.
Future<void> getData() async {
  print("Fetching data...");
}

3. await

The await keyword pauses the execution of the async function until the Future completes.
Future<String> fetchData() {
  return Future.delayed(
    Duration(seconds: 2),
    () => "Data Loaded",
  );
}

Future<void> main() async {
  print("Start");

  String data = await fetchData();

  print(data);
  print("End");
}

4. Stream

A Stream provides multiple values over time.
Unlike Future, which returns only one value, a Stream can return many values continuously.
It is used in Live chat, Notifications, Sensor data, Real-time updates

Future :- Represents a value available in the future.
async :- Makes a function asynchronous.
await :- Waits for a Future to complete.
Stream :- Provides continuous asynchronous data.
